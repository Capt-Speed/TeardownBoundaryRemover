# Third-party dependencies

The application runtime source intentionally uses only .NET / Windows Forms APIs. No third-party runtime NuGet packages are required by the project.

Protected release builds use Dotfuscator Community 7.7 as a build-time-only tool. It is not shipped as an application runtime dependency. Dotfuscator Community is free for personal use and is governed by PreEmptive's license terms: https://marketplace.visualstudio.com/items?itemName=PreEmptiveSolutions.dotfuscator-community
